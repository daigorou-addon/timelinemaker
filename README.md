# TimelineMaker（年表メーカー）

出来事を入力するだけで、SNS向けの年表画像（PNG）を作れるWebツールです。ブラウザ内ですべて処理され、データや写真はどこにも送信されません。

- ☕ **Support Me**: https://buymeacoffee.com/daigorou

## できること
- **タイプ6種**：A 横年表／B 縦年表（スマホ・SNS向き）／C ポスター横／D ポスター縦／E ロードマップ／F 円形年表
- **カラーテーマ5種**：ネオン（初期設定・黒背景）／ポップ／シンプル／パステル／レトロ
- **サンプル7種**：ゲーム機の歴史／わたしの人生年表／インターネットの歴史／猫と暮らした記録／日本の歴史／京都・大阪 旅行プラン／日本の一年（行事）
- **画像サイズ**：自動／TikTok・リール 9:16／Instagram 1:1／YouTube 16:9
- **年の表記**：西暦／和暦＋漢数字（明治・大正・昭和・平成・令和、元年表記に対応）
- **出来事の編集**：追加・削除・並べ替え・日付順ソート、出来事ごとの色指定、写真の追加（表示範囲の調整つき）
- **戻す・進める（↶ ↷）**：編集を最大30回分さかのぼれます
- **保存／読み込み**：途中の状態を `.json` ファイルで書き出し、あとから読み込んで続きを再開（写真も含む）
- **PNGで保存**：左パネル下の固定ボタンから書き出し
- **入力内容の自動保存**：ブラウザ（localStorage）に自動で保存
- **表示テーマ（ライト/ダーク）**：PC・スマホとも ☾/☀ ボタンで切り替え（選択は保存）。未選択のときは、スマホは端末の設定に合わせ、PCはダークで表示
- **6言語対応**：日本語／English／한국어／简体中文／繁體中文／Español
